# momr

Analyzes shotgun metagenomic data.

Compatibility updates by Renova.

Uses the vector interface for a paired Wilcoxon test and updates package metadata and help tags.

## Installation

```r
install.packages("momr", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `1.1.9001` is based on [CRAN 1.1](https://cran.r-project.org/package=momr).
